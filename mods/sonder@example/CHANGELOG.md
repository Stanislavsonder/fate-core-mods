# Changelog

## 1.1.0

Rebuilt against the renamed mod SDK: dependencies moved to
`@fate-app/mod-types` / `@fate-app/mod-build` 2.0.0 (the `@fate-core`
packages were unpublished) and `sdk` raised to `^2.0.0` to match the app's
SDK_VERSION. No functional changes to the mod itself.

## 1.0.1

Documentation-only update — no functional changes. Published to prove out the
registry's update flow (fresh version, same hashes-pinned-to-latest model).

## 1.0.0

Initial release. Migrated from `packages/example-mod` in the main
`fate-core` repo, where it served as the Phase 2 integration fixture.
